# Inkwell Books

Front-end only bookstore (HTML, CSS, JavaScript, jQuery). There is no server: all data is saved in the browser (localStorage).

Open `index.html` or `login.html` (for example with the Live Preview extension). `index.html` opens the shop.

Default admin account: `admin@gmail.com` / `admin123`

## What it does

**Customers**
- Browse books by genre, search by title or author
- Save books to a **wishlist** with the heart button (see it in the shop sidebar and on the account page)
- Add books to the bag and check out

**Admin**
- Dashboard with revenue, best sellers and recent orders
- Books: add / edit stock / delete, manage genres, see how many customers wishlisted each book
- Orders, customers and revenue pages

12 sample books are added the first time the site opens.
